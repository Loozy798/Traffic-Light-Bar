# Traffic Light Bar 🚦

原生 macOS 状态栏资源监控工具。红绿灯提示当前系统压力，点击即可查看 CPU、内存、网络、磁盘和电池；需要分析来源时打开详细仪表盘。

## 功能

- **状态栏**：仅红绿灯，或搭配 CPU、内存、上下行速度；左键打开面板，右键打开操作菜单。
- **紧凑面板**：大字号 CPU / 内存占用、上下行速度、可复制 IP、磁盘剩余空间、电池供电状态与高 CPU 进程摘要；显示项目可自定义。
- **系统概览**：最近五分钟的 CPU、内存和双向网络趋势；压缩内存、交换空间、内存压力及磁盘容量详情。
- **进程排行**：CPU / 驻留内存排序、进程名称或 PID 搜索；支持多核心 CPU 超过 100% 和带空格的应用名称。
- **偏好设置**：1 / 2 / 5 秒刷新、进程提醒阈值、状态栏内容、弹窗项目、原生登录启动设置与错误反馈。
- **生命周期**：暂停 / 恢复；睡眠停止采样，唤醒重新建立基线；缺失数据和暂停区间不连接趋势线。
- **键盘**：应用激活时 `⌘D` 打开仪表盘，`⌘⇧P` 显示状态面板，`⌘,` 打开偏好设置。

界面跟随系统深浅色；日常仅状态栏常驻，打开仪表盘 / 设置时显示 Dock 图标，关窗后继续监控。

## 指标说明

- CPU 使用相邻系统 ticks 差值，包含 nice 时间；首次采样显示 `—`，不使用开机以来平均值。
- 绿灯：CPU < 50%；黄灯：CPU ≥ 50%；红灯：CPU ≥ 80%。系统内存压力和温控状态可以提高警示级别，三处界面使用同一规则。缺少有效 CPU 数据时显示等待状态。
- 内存占用与系统内存压力分别展示。磁盘容量不参与性能负载判断；APFS 可用容量包含系统允许回收的空间，约每 30 秒更新。
- 网络采用 64 位接口计数和实际单调时间差，汇总有地址的 `en*` 物理接口，避免重复统计 VPN / 点对点隧道。切网、计数重置、长间隔时重新建立基线；IP 显示其中首个接口的地址。
- 速度采用十进制 KB/s、MB/s；容量采用二进制 KiB、MiB、GiB。本次网络累计只包含实际监测区间，暂停 / 睡眠期间的流量不计入。
- 进程每 5 秒通过系统 `ps` 读取 CPU 和 RSS。进程 CPU 是系统提供的近期统计，以单核心 100% 计，与概览的全机 CPU 百分比口径不同；不代表真实能耗或功率。
- 电池区分电源供电与实际充电；剩余时间由系统估算，系统未提供时不显示。
- 访问失败显示不可用，不会被解释成“占用为零”或“系统正常”。

## 构建与运行

需要 macOS 15.6+ 和支持该工程的 Xcode / macOS SDK（工程包含 Icon Composer 资源）。无第三方依赖。

```sh
./script/build_and_run.sh              # 停止旧实例、构建、本地签名、启动
./script/build_and_run.sh --dashboard  # 同时打开仪表盘
./script/build_and_run.sh --verify     # 验证构建与进程启动
./script/build_and_run.sh --debug      # LLDB
./script/build_and_run.sh --logs       # 系统日志
```

Codex 的 Run 按钮也指向同一脚本。构建产物默认位于 `/private/tmp/traffic-light-bar-$UID`，避免 iCloud / FileProvider 为产物附加属性而导致签名失败；可用 `TLB_DERIVED_DATA` 覆盖。构建日志位于 `/private/tmp/traffic-light-bar-build.log`。

该脚本使用本地临时签名，适合开发验证。正式分发请在 Xcode 配置自己的 Developer ID、Hardened Runtime 签名与公证。应用采用直接分发配置，未启用 App Sandbox，以便读取全系统进程；不需要管理员权限。登录启动通过 `SMAppService` 管理，可能需要系统批准，开发目录中的临时构建不适合长期注册登录项。

## 验证

```sh
./script/test.sh              # 30 项计算、解析、边界和趋势回归断言
./script/test_integration.sh  # 实际采样、暂停恢复、睡眠唤醒和偏好持久化
```

在正常系统权限下运行集成检查。宿主执行环境限制进程枚举时会打印受限说明。应用自身的 CPU / 内存开销随构建方式、窗口和图表显示情况变化，不作固定占用承诺。

数据仅留在本机，趋势只保存在内存中，退出后清除。
